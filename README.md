# Sabbir Ahmed — Portfolio

A static HTML, CSS and JavaScript portfolio designed to deploy directly with GitHub Pages. No Node.js, React, build tools, or paid hosting required.

## Files
- `index.html` — page content
- `style.css` — layout, colors, responsive design and animations
- `script.js` — mobile navigation, reveal animations and current year
- `assets/` — add your photo, CV and project images here

## Publish with GitHub Pages
1. Create a **public** repository named `portfolio` in your GitHub account.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder to the repository root. Do not upload the ZIP file itself.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then click **Save**.
6. Wait a few minutes. Your site will be available at `https://YOUR-USERNAME.github.io/portfolio/`.

For a username homepage instead, create a public repository named exactly `YOUR-USERNAME.github.io`, upload the same files to its root, and use `https://YOUR-USERNAME.github.io/`.

## Personalize before publishing
1. In `index.html`, replace `YOUR_EMAIL@example.com` in both the email link and visible text with your real email.
2. Add your CV to `assets/` (for example `Sabbir-Ahmed-CV.pdf`) and add a link to it where you want it displayed.
3. Review dates, titles, project details and competition claims for accuracy.
4. Add your own images to `assets/` and update the corresponding HTML.

## Editing online
Open a file in the GitHub repository, click the pencil icon, edit it, then click **Commit changes**. GitHub Pages will automatically redeploy after the commit.
